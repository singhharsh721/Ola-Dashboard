# Ola Ride Analytics Dashboard

# Short Description

**Ola Ride Analytics Dashboard** is an interactive **Power BI data analytics project** designed to analyze ride-booking performance, revenue, cancellations, customer and driver ratings, vehicle-type performance, and booking trends.

The dashboard transforms raw Ola ride-booking data into actionable business insights through interactive visuals, KPI cards, slicers, tables, and trend analysis. It provides a consolidated view of operational and customer-level performance, helping identify revenue patterns, cancellation drivers, popular vehicle categories, and booking behavior over time.

## Tech Stack

* **Power BI Desktop** – Dashboard development and data visualization
* **Power Query** – Data cleaning, transformation, and preparation
* **DAX** – Measures, KPIs, calculations, and analytical logic
* **Microsoft Excel / CSV** – Data preparation and source data handling
* **SQL** – Data extraction, querying, and data preparation from relational datasets

## Data Source

**Ola Ride Booking Dataset** containing ride-level information such as:

* Booking ID and booking date
* Customer ID
* Vehicle type
* Booking status
* Booking value
* Payment method
* Ride distance
* Customer ratings
* Driver ratings
* Customer cancellation reasons
* Driver cancellation reasons

The dataset was prepared and transformed for analytical reporting in Power BI.

## Dashboard Features & Highlights

### 1. Overall Performance Analysis

* Total bookings and total booking value
* Booking status breakdown
* Success, customer cancellation, driver cancellation, and driver-not-found analysis
* Ride volume trends over time
* Date-based interactive filtering

### 2. Vehicle Type Analysis

* Performance comparison across **Prime Sedan, Prime SUV, Prime Plus, Mini, Auto, Bike, and E-Bike**
* Total booking value by vehicle type
* Successful booking value
* Average distance travelled
* Total distance travelled

### 3. Revenue Analysis

* Revenue comparison by payment method
* Analysis of **Cash, UPI, Credit Card, and Debit Card**
* Daily revenue/travel trends
* Identification of high-performing payment categories
* Top 5 customers based on booking value

### 4. Cancellation Analysis

* Total cancelled bookings and cancellation rate
* Customer cancellation reasons
* Driver cancellation reasons
* Visual breakdown of major cancellation categories
* Identification of key operational issues affecting cancellations

### 5. Ratings Analysis

* Driver ratings across different vehicle categories
* Customer ratings across vehicle categories
* Comparison of rating patterns between customers and drivers
* Identification of consistently high-rated vehicle segments

### 6. Interactive Dashboard Experience

* Dynamic **date slicers** for customized analysis
* Page-wise navigation between:

  * Overall
  * Vehicle Type
  * Revenue
  * Cancellation
  * Ratings
* Interactive charts, tables, KPI cards, and filters
* User-friendly dashboard layout for quick business analysis

## Key Business Insights

The dashboard helps answer important business questions such as:

* Which vehicle types generate the highest booking value?
* What percentage of bookings are successfully completed?
* What are the major reasons for customer and driver cancellations?
* Which payment method contributes the most revenue?
* How does ride volume change over time?
* Which customers contribute the highest booking value?
* How do customer and driver ratings vary across vehicle categories?
* Which vehicle categories deliver higher average and total travel distance?

## Project Objective

The primary objective of this project is to demonstrate how **business intelligence and data visualization techniques can convert raw ride-booking data into meaningful operational insights**.

It showcases practical skills in:

**Data Cleaning → Data Transformation → Data Modeling → DAX Analysis → Dashboard Design → Business Insights**

## Project Outcome

This project demonstrates an end-to-end **Data Analyst / Business Intelligence workflow** using Power BI, with a strong focus on KPI reporting, interactive visualization, trend analysis, customer behavior, revenue analysis, and operational performance.

It can be used as a portfolio project to demonstrate practical expertise in **Power BI, DAX, data cleaning, visualization, and analytical storytelling**.
